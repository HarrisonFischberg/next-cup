# Replica artifacts

Outputs: recon map, architecture, design tokens, feature matrix, parity diff,
brand sweep, listing lint.

## Intentional differences

Each place the reference conflicted with accessibility, privacy, honest
pricing, or a safeguard. A removed harmful pattern is not a parity defect.

| Screen / flow | Reference behavior | Our behavior | Reason |
| --- | --- | --- | --- |
| Brew logging | One reference fixes the target output before an espresso shot | Actual values are always recorded and editable later | Honest record; user feedback |
| Paid features | One reference locks logs, dial-in, widgets and saved presets behind a paid tier | Everything free; nothing the user built is ever locked | Free app; no dark patterns (safeguard 9) |
| Privacy | One reference declares data linked to the user | No collection, no analytics, no accounts | Intake; no unnecessary data (safeguard 7) |
| Engagement | Streaks and badges | Stats only; any streak never pressures or punishes | No dark patterns (safeguard 9) |
| Community | Recipe feed and sharing | None | Social out of scope by intake |
| Accessibility | One reference declares no accessibility features | All five declared and verified | Intake accessibility requirements |
