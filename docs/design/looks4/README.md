# Round 4: twenty looks from real iOS apps (2026-10-26)

Rounds 1 to 3 were rejected (palette swaps, themed gimmicks, native-metaphor looks). Each look here
borrows the *structure* of a specific iOS app found on Mobbin, so no two share a layout idea.
Every strip shows Journal, Timer (frozen at 1:18) and Log, in light then dark.

| # | Look | Mobbin reference | Idea |
|---|------|------------------|------|

| 22 | Atmosphere | Insight Timer player + journal | Full-bleed bean-colour field, thin countdown, mood marks, serif quotes |
| 23 | Workout | Nike Training Club | Black clock bar, steps as a circuit led by load, giant history total |
| 24 | Stack | BitePal | Big white number cards with ring END button, "This week" sheet |
| 25 | Timeline | Structured | Day-planner pills on a dashed spine, tinted countdown, checklist |
| 26 | Ruler | Brink sleep timer | Everything read and set on sliding tick rulers |

| 28 | Route | Lyft | Recipe as a route with stops, ride sheet with ETA, rating flow |
| 29 | Bubbles | Tripadvisor | Cup reviewed like a place, bubble ratings, bubble progress |
| 30 | Data Fields | Garmin Connect | Watch-face data fields, range picker, goal rings |

| 32 | Ledger | Future Pro | Serif title, ring grid, scannable data tables |
| 33 | Sets | Bevel | Pours as sets with value pills, floating mini player |
