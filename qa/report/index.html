Release recommendation

Merge the fixes; do not yet claim accurate bag reading. On 30 synthetic labels (no real photos yet), every release blocker seen in the baseline is gone in the final runs (60 runs plus 36 repeats, 0 blockers): Apple no longer invents roast dates, follows text printed on a label, or mixes two bags. Anthropic had none to begin with. Accuracy after fixes: Anthropic precision 99.5% (97.5–99.9), invented 0.8%; Apple precision 94.7% (91–97), invented 2.7%. Apple still puts the roaster in the name on 5 of 30 labels and failed 1 of 30 answers on schema, so every field still needs the user's review, as the editor already says.

Release gate (provisional, set from this baseline and to be re-set on real photos): 0 release blockers in every run; invented-value rate at most 3% per provider; precision at least 95% (Anthropic) and 90% (Apple) on at least 100 reviewed real bags; physical-iPhone matrix rows A to G passed. None of the real-photo or device conditions are met yet, so this is not a release sign-off.

Implemented

  • Live eval harness in the app's own tests (NextCupTests/BeanCaptureEvalTests.swift): real fixture bytes through PhotoSanitizer, BagRecognition, AIClient or AppleIntelligence, and BagRecognition.draft. Skipped (never passed) without QA_ROOT.
  • qa/run-eval.sh: refuses to run unless .env.qa.local is git-ignored, untracked, chmod 600 and filled; passes only the file path; budget limits on requests and estimated dollars; sequential requests.
  • 30 synthetic fixtures with exact labels (qa/tools/make_synthetic.py), split dev/held-out by product, plus a manifest and labeling workflow for real photos (qa/README.md).
  • Deterministic scorer with Wilson intervals (qa/tools/score.py) and its self-check; this report (qa/tools/build_report.py).
  • LabelEvidence (NextCupKit): conservative roast date, weight, farm and roast-level readers used on the Apple path and in the new no-AI fallback.
  • Prompt v3 for bag recognition with field definitions and date rules; placeholder scrub.
  • Barcode fixes, Apple AI suggestions with Accept / Dismiss, Vision-only fallback when no AI model is set up.
